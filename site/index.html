Hospital price file catalog

Every CMS-certified US hospital, with the price files listed in its cms-hpt.txt. Links only, no price data is downloaded. Source: Moqri-Lab/hospitals.
Sources and definitions
  • Hospital list: CMS Hospital General Information (data.cms.gov dataset xubh-q36u, July 2026 release; CSV, data dictionary). 5,419 Medicare-certified hospitals, one row per CMS Certification Number (CCN).
  • Bed count: BED_CNT (total beds) from the CMS Provider of Services file, hospital extract Q3 2026 (CSV), active providers only, joined on CCN. Beds are reported per CCN, and one CCN can cover several campuses (see the "Campuses" column, counted from the hospital's own cms-hpt.txt).
  • Price file links: each hospital's own cms-hpt.txt, which CMS requires at the root of the hospital website (45 CFR 180, CMS Hospital Price Transparency, CMS file specification). Format, size and date come from an HTTP HEAD request; price files are never downloaded.
  • Website leads (candidates only, each verified against the live cms-hpt.txt): health-system name rules and hostnames from the open TPAFS / DoltHub transparency-data hospital links (CC BY-SA 4.0), official websites (P856) of US hospitals in Wikidata, the open knowledge base behind Wikipedia (CC0; matched items with links in wikidata_hospitals.csv), and other open, public lists of hospital price-file pages (full attribution in the README).
  • Name in cms-hpt.txt: the location name the hospital itself uses for this price file in its cms-hpt.txt (it can differ from the CMS name, e.g. after a rebrand); the link opens the hospital's price transparency page. One CMS hospital can have several names or files.
  • Web columns: the website each source gives for the hospital (one column per source, joined on CCN, the CMS provider ID; green = confirmed by that site's cms-hpt.txt): a health-system rule, Wikidata (item linked), TPAFS/DoltHub hospitalpricingfiles.org (HPF.org), or "Claude": a website Claude (AI) found by reviewing hospitals no other source got right, usually ones now run by a different system (domains.csv, with a note for each). A website is used only if its own cms-hpt.txt names the hospital.
  • cms-hpt.txt access: CMS requires every hospital to post cms-hpt.txt at its website root so its price files can be found automatically (45 CFR 180.50). When a site refuses our automated request (for example HTTP 403 from bot protection), times out or has a broken certificate, the reason is shown in red as a possible accessibility problem. We do not bypass bot protection; instead the file is read from the latest public archive copy, Internet Archive or Common Crawl (dated and linked), or from a copy saved in a browser.
  • Exempt: federally owned or operated hospitals (VA, DoD and Indian Health Service) are deemed compliant and are not crawled. State forensic hospitals that treat only people in penal custody are also deemed compliant; state psychiatric hospitals are marked "possibly exempt" because public data does not say which are purely forensic, and they are still crawled. Tribally operated hospitals are not exempt (45 CFR 180.30(b)).
