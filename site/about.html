Every CMS-certified US hospital, with the price files listed in its cms-hpt.txt. Links only: no price data is downloaded. Code and data: Moqri-Lab/hospitals.

Sources and definitions
  • Hospital list: CMS Hospital General Information (data.cms.gov dataset xubh-q36u, July 2026 release; CSV, data dictionary). 5,419 Medicare-certified hospitals, one row per CMS Certification Number (CCN).
  • Bed count: BED_CNT (total beds) from the CMS Provider of Services file, hospital extract Q3 2026 (CSV), active providers only, joined on CCN. Beds are reported per CCN, and one CCN can cover several campuses (see the "Campuses" column, counted from the hospital's own cms-hpt.txt).
  • Price file links: each hospital's own cms-hpt.txt, which CMS requires at the root of the hospital website (45 CFR 180, CMS Hospital Price Transparency, CMS file specification). Format, size and date come from an HTTP HEAD request; price files are never downloaded.
  • Website leads (candidates only, each verified against the live cms-hpt.txt): health-system name rules and hostnames from the open TPAFS / DoltHub transparency-data hospital links (CC BY-SA 4.0), official websites (P856) of US hospitals in Wikidata, the open knowledge base behind Wikipedia (CC0; matched items with links in wikidata_hospitals.csv), and other open, public lists of hospital price-file pages (full attribution in the README).
  • Name in cms-hpt.txt: the location name the hospital itself uses for this price file in its cms-hpt.txt (it can differ from the CMS name, e.g. after a rebrand); the link opens the hospital's price transparency page. One CMS hospital can have several names or files.
  • Web columns: the website each source gives for the hospital (one column per source, joined on CCN, the CMS provider ID; ✓ = this source gave the website whose cms-hpt.txt was read): a health-system rule, Wikidata (item linked), TPAFS/DoltHub hospitalpricingfiles.org (HPF.org), or "Claude": a website Claude (AI) found by reviewing hospitals no other source got right, usually ones now run by a different system (domains.csv, with a note for each). A website is used only if its own cms-hpt.txt names the hospital.
  • cms-hpt.txt access: CMS requires every hospital to post cms-hpt.txt at its website root so its price files can be found automatically (45 CFR 180.50). When a site refuses our automated request (for example HTTP 403 from bot protection), times out or has a broken certificate, the reason is shown in red as a possible accessibility problem. We do not bypass bot protection; instead the file is read from the latest public archive copy, Internet Archive or Common Crawl (dated and linked), or from a copy saved in a browser.
  • cms-hpt.txt compliance (green / red / amber): checks only the requirement that each hospital post a machine-readable cms-hpt.txt at its website root listing its price file (45 CFR 180.50(d)(6)); it does not judge the price files themselves. Compliant: a live cms-hpt.txt lists the hospital. Not compliant: the hospital's website has no cms-hpt.txt, its file omits the hospital, or every price file it lists for the hospital returns HTTP 404 (checked with a HEAD request, which a few servers answer differently from a download). Inaccessible (amber): we could not confirm either way, because the website refuses automated requests (for example bot protection returning HTTP 403, though the file may open in a browser), the website is unknown or uncertain, or there was a network error; the reason is shown under the flag. A failure is only counted when we are sure the website is the hospital's (it lists the hospital, or two independent sources agree). This is an automated check, not a legal determination.
  • Confidence (0-100) that a price file belongs to the CMS hospital. Base, by match method: name match = name similarity x 100; reviewed by Claude = 85; only entry naming the hospital's city = 70; only hospital on that website = 65; low-confidence = similarity x 60. Plus 5 for each extra independent source giving the same website (up to +15); minus 10 if the cms-hpt.txt came from a public archive, minus 5 if from a saved copy. High = 80 and up, medium = 60-79, low = under 60.
  • Exempt: federally owned or operated hospitals (VA, DoD and Indian Health Service) are deemed compliant and are not checked. State forensic hospitals that treat only people in penal custody are also deemed compliant; state psychiatric hospitals are listed as "possibly exempt" on the exempt hospitals page, because public data does not say which are purely forensic. Tribally operated hospitals are not exempt (45 CFR 180.30(b)). Exempt and possibly exempt hospitals →
