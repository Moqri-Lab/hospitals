What this is

An open, research-oriented catalog of where every Medicare-certified US hospital publishes its price transparency files. For each hospital it lists:

  • Hospital information from CMS: CMS Certification Number (CCN), name, address, type, ownership and bed count.
  • Every field of its cms-hpt.txt: location name, source page, price-file (MRF) link, contact name and email.
  • Price-file metadata: format, size, last-modified date and HTTP status, from an HTTP HEAD request.

Price data is never downloaded. The catalog lists the links; researchers fetch the files they need themselves.

Finding hospital websites

No official source lists hospital websites, so each source below only proposes a candidate. A website is used only when its own live cms-hpt.txt names the hospital.

Wikidata
The "official website" (P856) of US hospital items, matched to a CMS hospital by name plus city or ZIP (matches).
OpenStreetMap
The website tag of hospitals (amenity=hospital or healthcare=hospital) in the US and Puerto Rico, from the Overpass API, matched by name within 25 km of the hospital's ZIP code (Census ZCTA gazetteer). 4,147 matches, each linked to its OSM object (matches). Data © OpenStreetMap contributors, available under the Open Database License.
TPAFS/DoltHub and nathansutton
Hostnames of the hospital price-transparency links in two open, community-maintained lists.
Health-system rules
Name patterns for large systems, such as "Ascension" → ascension.org (rules).
Inferred
For hospitals no source covers: another website's cms-hpt.txt that lists the hospital, or a domain built from its name (such as wiregrassmedicalcenter.org). Kept only if the home page shows the hospital's street address, or ZIP and city, or the website lists the hospital's exact name and already serves hospitals in the same state (evidence).
Claude
Websites found by Claude (AI) on review, usually for hospitals now run by a different system (list, with a note for each).

Compliance check

The flag checks one requirement only: that each hospital posts a machine-readable cms-hpt.txt at its website root that lists its price file (45 CFR 180.50(d)(6)). It does not judge the price files themselves. It is an automated check, not a legal determination.

  • ✓ compliant A live cms-hpt.txt lists the hospital.
  • ⚠ inaccessible We could not confirm either way. The website refuses automated requests (for example HTTP 403 from bot protection, though the file may open in a browser), the website is unknown or uncertain, a price-file server does not answer HEAD requests, or there was a network error. The reason is shown under the flag.
  • ✗ not compliant The hospital's website has no cms-hpt.txt, its file omits the hospital, or every price file it lists returns HTTP 404. Counted only when we are sure the website is the hospital's: its file lists the hospital, or two independent sources agree.

Table columns

Name in cms-hpt.txt
The location name the hospital itself uses for a price file. It can differ from the CMS name, for example after a rebrand; the link opens the hospital's price transparency page.
Web columns
The website each source gives, joined on CCN. ✓ marks the source whose website's cms-hpt.txt was read.
Campuses
Distinct location names attached to the CCN in its cms-hpt.txt.
Confidence (0-100)
How sure the catalog is that a price file belongs to the CMS hospital. Base, by match method: name match = name similarity × 100; reviewed by Claude = 85; only entry naming the hospital's city = 70; only hospital on that website = 65; low-confidence = similarity × 60. Plus 5 for each extra independent source giving the same website (up to +15); minus 10 if the cms-hpt.txt came from a public archive, minus 5 if from a saved copy. High = 80 and up, medium = 60-79, low = under 60.

Totals and the negotiated-price estimate

The home page counts each distinct price-file link once. The number of negotiated prices is an estimate, because price files are never downloaded. It divides each file's size (from the HEAD response; files reporting no size get the median size of their format) by the typical space one payer-specific negotiated price takes in the CMS template:

FormatBytes per price (typical, range)
CSV220 (120-400): "tall" files use a row per payer and plan; "wide" files share columns
JSON300 (180-500)
zip / gzip22 (12-40), about 10:1 compression

The range on the home page uses the high and low byte counts. Gross and cash prices, notes and repeated rows also take space, so treat it as an order of magnitude.

Exempt hospitals

Federally owned or operated hospitals (VA, DoD and Indian Health Service) are deemed compliant and are not checked. State forensic hospitals that treat only people in penal custody are also deemed compliant; state psychiatric hospitals are listed as "possibly exempt", because public data does not say which are purely forensic. Tribally operated hospitals are not exempt (45 CFR 180.30(b)). Both groups are listed below, without the website and price-file fields.

Exempt

Federally owned or operated: VA, DoD and Indian Health Service.

Possibly exempt

State-run psychiatric hospitals; exempt only if purely forensic. Any cms-hpt.txt data found for them stays in catalog.csv.

Run it yourself

pip install -e .
python -m hpthub cms-download          # CMS files into data/cms/
python -m hpthub registry              # data/registry/hospitals.csv
python -m hpthub discover --limit 100  # cms-hpt.txt for the 100 largest
python -m hpthub site                  # data/catalog.csv, CATALOG.md, data.json

A GitHub Action re-crawls every hospital weekly. To fix a missing or wrong website, add a row ccn,domains to domains.csv and open a pull request; the next crawl verifies it. Code is MIT-licensed; CMS data is public domain. Source: Moqri-Lab/hospitals.
